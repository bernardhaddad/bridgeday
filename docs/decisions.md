# Decisions

One line per decision, newest first: date, decision, reason, alternative rejected.

- 2026-10-30 Leave Intent Index = the moat: first-party, anonymous counts of "I'm taking this break" via GoatCounter events (cookie-free, no personal data, unique visitors per event). Raw counts stay in git-ignored private/ (a public repo would give them away); public site shows only a "most chosen" badge at >=5; paid file drops rows <3. Rejected: own backend (cost, privacy liability), Google Analytics (cookies, consent banners).

- 2026-10-30 Dataset audit fixes: library end_year respected (LK 2027 skipped); declared weekend workdays exported and counted open; breaks/bridges crossing 1 Jan counted; office-weekend overrides for AI CD KN NE PY TK VE MR (Sat-Sun, high/medium confidence), LY PS (Fri-Sat), SO (Fri), NP (Sat; medium); regional holidays count nationally when >=90% of regions are off on that date (any name); bridge = leave strictly between days off; countries without population kept with blank population; local names only when unambiguous; wording: projections, not official estimates.

- 2026-10-30 Holiday source switched from Nager.Date to the `holidays` library (MIT, pinned 0.107). Nager.Date's terms (2023-09-15) forbid "publish or operate your own holiday portal" and require sponsorship for commercial use. The library also gives each country's official weekend (Hong Kong overridden to the office weekend), regional holidays and offline generation. Uninhabited territories dropped.
- 2026-10-30 Premium data = Global Long-Weekend & Absence Index: population-weighted daily figures, day x country rows, country pairs. Countries without a World Bank population are listed, never estimated. Free headline page drives traffic; raw files are the paid product.

- 2026-10-30 Paid product = printable planner PDF per country (owner chose it). Hand-written PDF (Helvetica, cp1252, Flate) keeps the stdlib-only rule; holiday names use the English field. Products are built locally, never in CI, because a public repo's Actions artifacts are downloadable and would give the product away.

- 2026-10-30 Budget plans only count breaks that bridge a weekday holiday or last 9+ days; otherwise single Fridays "win" by counting weekends you already had.
- 2026-10-30 From October the index and /cc/ redirect point at next year: that is what people search then.
- 2026-10-30 No SRI on the AdSense and GoatCounter scripts: both vendors serve changing files from fixed URLs, so a hash would break them. They load only when the owner configures them.
- 2026-10-30 Deploy is gated on `vars.BRIDGEDAY_DEPLOY` and only runs on schedule or manual dispatch. The workspace repo is private (Pages needs a paid plan there), so the intended home is a separate public repo using `.github/workflows/site.yml`; creating it is the owner's call.
- 2026-10-30 Scheduled job runs `make test`, not lint: a new ruff release must not freeze the site. Data covers one year past the last page.
- 2026-10-30 Python standard library only at runtime: an unattended job has no dependency drift to break it. Rejected: Jinja/static-site generators.
- 2026-10-30 Niche = holidays + leave optimizer: free keyless data, evergreen and yearly-recurring search demand, computed (not AI-written) content, and a natural travel-affiliate moment. Rejected: currency pages (dominated by banks and Wise/XE), AI content farms (spam policy risk), trading bots (not passive, capital at risk).
- 2026-10-30 Build on the session model at high effort; tests written alongside, reviewers on Opus.
- 2026-11-02 Corrections over the library: `src/bridgeday/corrections.json` (234 entries: add, remove, move, rename, scope, observance), each with the official or reliable source it rests on, applied after the library in `country_year()` so the daily rebuild keeps them; `check_corrections()` reports any that stop taking effect. They come from a Claude audit of all 244 countries (tools/bridgeday_audit on claude/fervent-wright-q7rq70): only findings a second, disproving pass confirmed against a source; findings resting on no source (GL, KI, CY) and inferences (ME 15 Nov 2027, KG public-sector-only days) left out. Whole-law fixes applied to both years: BF Law 001-2026/ALT, SY Decree 188/2025, GW Decree 01/2023, GH Act 601 as amended 2025, NE Ordinance 2026-12. HK reads the library's public+optional categories (its gazetted general holidays, when offices close). AF weekend = Friday (government week Saturday to Thursday noon). Data stays computed, not AI-written: every correction is a sourced fact.
